# Project 001: Network Traffic Analysis

## Project Overview
This project demonstrates my hands-on experience
analyzing network traffic using Wireshark.

## Tools Used
- Wireshark
- macOS
- TCP/IP protocols

## Skills Demonstrated
- Network packet analysis
- TCP three-way handshake
- IP address investigation
- Network traffic filtering
- Security incident documentation

## Investigation Summary
I investigated communication between an internal
device and an external server using TCP port 443.

During the investigation, I observed TCP
retransmissions and duplicate acknowledgments.

The available evidence did not confirm malicious
activity.
