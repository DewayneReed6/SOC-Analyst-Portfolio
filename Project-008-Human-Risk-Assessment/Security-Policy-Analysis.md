# Security Policy Analysis

## Objective

Evaluate recommended organizational security policies designed to reduce human-centered cybersecurity threats and improve security awareness.

## Assessment Environment

- Platform: TryHackMe
- Room: Humans as Attack Vectors
- Learning Path: SOC Level 1
- Module: Security Policy
- Role: Junior SOC Analyst
- Status: Completed Training Lab

## Recommended Security Policies

| Policy | Recommended Control | Priority |
|---|---|---|
| Password Security | Strong, unique passwords and password managers | High |
| Authentication | Enforce multi-factor authentication | High |
| Email Security | Phishing detection and suspicious email reporting | High |
| Access Control | Implement least privilege | High |
| Security Awareness | Regular employee cybersecurity training | Medium |
| Incident Reporting | Establish clear reporting and escalation procedures | High |
| Data Protection | Restrict unauthorized sharing of sensitive information | High |
| Remote Access | Require secure and approved remote connections | High |

## Risk Mitigation Strategy

- Reduce exposure to credential theft.
- Prevent unauthorized access to sensitive systems.
- Improve employee recognition of social engineering.
- Establish consistent security reporting procedures.
- Review and update security policies regularly.

## SOC Analyst Responsibilities

- Monitor suspicious employee account activity.
- Investigate potential security policy violations.
- Document security risks and incidents.
- Escalate identified threats to appropriate teams.
- Recommend preventive and corrective security controls.

## Evidence Limitations

The TryHackMe training room was successfully completed. Individual policy assessment results were unavailable for retrieval after completion.

The policies listed in this report represent recommended security practices rather than verified deficiencies within the lab organization.

## Conclusion

Effective security policies help organizations reduce human-centered threats, protect sensitive information, and improve incident response capabilities.
