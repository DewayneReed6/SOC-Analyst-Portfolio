## 2. Executive Summary

This security assessment focused on human-centered cybersecurity threats through the TryHackMe Humans as Attack Vectors training room.

The assessment covered employee security risks, social engineering techniques, and organizational security policies.

The objective was to develop practical skills in identifying potential human-related vulnerabilities and recommending appropriate security controls.

## 3. Assessment Scope

## 5. Potential Security Threats

| Threat | Potential Impact | Illustrative Severity |
|---|---|---|
| Phishing | Credential theft | High |
| Social Engineering | Unauthorized access | High |
| Weak Authentication | Account compromise | High |
| Information Disclosure | Sensitive data exposure | Medium |
| Poor Security Awareness | Increased attack exposure | Medium |

These threats represent illustrative assessment scenarios, not confirmed security incidents.

## 6. Recommended Response Actions

- Review suspicious employee account activity.
- Investigate reported phishing attempts.
- Preserve relevant security evidence.
- Escalate confirmed threats to senior analysts.
- Coordinate corrective actions with IT personnel.
- Document investigation outcomes.

## 7. Preventive Security Recommendations

- Enforce multi-factor authentication.
- Implement strong password policies.
- Conduct regular security awareness training.
- Apply least privilege access controls.
- Establish phishing reporting procedures.
- Regularly review security policies.
